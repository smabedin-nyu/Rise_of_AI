# Rise_of_AI

This is my Project for the Rise of AI project, simply titled "Rise of AI" (Got lazy with it) <br> <br>
Here, I have made 6 scenes: 3 menu screens and 3 level scenes. The menu screens are simple, one starting menu, one death screen (that changes depending on the number of lives left) and one victory screen after finishing all 3 levels. <br>
My 3 levels are simple: <br>
Level 1: It is like a starter level with no enemies that are present. The only AI visible here is a lerping fairy (which I think counts?) I decided to have a non enemy level because I wanted the player to get used to the movement of the character and also get used to the platforming, and also to make subsequent levels slightly harder. To complete each level, reach and obtain the coin in the level. <br>
Level 2: This level features a few green slimes, which are wandering AIs in my game. Stomp on them to defeat them. A simpler level but there are a bunch of slimes to deal with that alternate back and forth <br>
Level 3: This level is the harder one with fast following purple slimes, which are a follower AI. Stomp on them to defeat them, and watch out for the one that comes for you as soon as you start the level. <br>

Controls: <br>
W-> Jump: The knight jumps upward <br>
A-> Run Left: The knight moves to the left (for some reason the spritesheet I found online doesn't have a move left sprite) <br>
D-> Run Right: The knight moves to the right <br>
R-> Restart Level: Press this button at any time to restart the level, but you also lose a life in the process <br>
ESC-> Quit Game: At any time, quits the game <br>
ENTER-> Continue: In any menu, pressing enter proceeds the game to go to the next level <br>
